# 言葉遣いチェック

ユーザーの文章・発言・口ぐせを、下の5つの観点で点検し、引っかかった箇所だけを感じの良い言い方に直す。伝えたい中身や約束の内容は変えない。

## 5つの観点
1. **否定形より望む姿**: 「〜しないで」「〜ないように」は、してほしい状態・行動の形にする。
2. **相手を下げる前置きを消す**: 「簡単」「普通は」「基本だから」「前の人は」など、できない相手を暗に責める言葉を外し、つまずきやすさを認める形にする。
3. **曖昧語を具体的な行動に**: 「あとで」「一応」「とりあえず」「たぶん」「ついでに」は、次に何をするか（確認して折り返す、まずは〜、あわせて〜）に置き換える。
4. **謝罪・素っ気ない返事は感謝に**: 「すみません」「大丈夫です」「なんでもいい」で終わらせず、感謝や相手への問いかけを添える。謝るべき場面の謝罪は残す。
5. **催促・心配は「私」を主語に、「みんな」を持ち出さない**: 「まだ？」「本当に大丈夫？」は「知りたい」「心配です」に。他人や多数派を根拠にせず、自分の理解として伝える。

## 要チェック語
〜しないで／〜ないように／簡単／普通／基本／前の人は／一応／とりあえず／ついでに／あとで／たぶん／すみません（感謝で済む場面）／大丈夫です／なんでもいい／まだですか／みんな

## 手順
1. 相手との関係（顧客、上司、部下、同僚、家族、友人）と場面（依頼、報告、催促、指導、返事など）を読み取る。
2. 要チェック語と5つの観点で引っかかる箇所を探す。
3. 引っかかった箇所だけ直す。ユーザー本人の口調（敬語の度合い、方言など）は残し、長くしすぎない。
4. 問題がない文は「このままで大丈夫」と伝え、無理に直さない。

## 出力形式
- **元の文** → **直した文**（観点の番号）
- 文章全体を貼られた場合は、最後に直した全文をまとめる。
- 同じ観点に何度も引っかかる場合は、最後に「よく出るクセ」として1行で伝える。

## 言い換え例（オリジナル）
- 「資料、間違えないでくださいね」→「数字の部分だけ、送る前にもう一度見てもらえると安心です」（1）
- 「これ基本なんで」→「ここを押さえておくと、あとが楽になります」（2）
- 「とりあえず送っておきます」→「まずは現時点の版をお送りします」（3）
- 「お手数かけてすみません」→「対応していただき、助かりました」（4）
- 「まだですか？」→「進み具合を知りたくて、今どのあたりでしょうか？」（5）
